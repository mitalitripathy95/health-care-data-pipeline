  ## Phase 11 — End-to-end deployment and testing

  This will be done last, after all code is complete.

  Deployment sequence:

  terraform init
  terraform fmt -check
  terraform validate
  terraform plan
  terraform apply

  Then:

  1. Create source schemas.
  2. Generate Tiny data.
  3. Load PostgreSQL and Azure SQL.
  4. Run ADF initial ingestion.
  5. Run Bronze Spark job.
  6. Run Silver Spark job.
  7. Run Gold Spark job.
  8. Export Gold data to ADLS.
  9. Load Snowflake.
  10. Run KPI procedures.
  11. Execute reconciliation tests.
  12. Execute incremental scenarios.
  13. Execute duplicate-trigger tests.
  14. Execute failure/recovery tests.
  15. Execute backfill tests.
  16. Execute privacy/tokenization tests.
  17. Capture monitoring and cost evidence.
  18. Run teardown.
